# AI Agent Task: Figma Code Connect Generation Script

## 🎯 Your Mission

You are tasked with building a Node.js script called `generateFigmaConnect.js` that generates `.figma.tsx` files for each React component, using the outputs from:

- **Phase 1:** Figma variant data (`figma-variants/`)
- **Phase 2:** Extracted component props and recipe variants (`components-props/`)

The goal is to enable seamless Figma-to-code handoff by mapping Figma variants and component props into a ready-to-use React wrapper for each component.

---

## 📋 What You Must Build

### Core Script Requirements

Create or enhance `scripts/generateFigmaConnect.js` with these capabilities:

1. **Scan Output Directories**
   - Read all YAML files in `components-props/` for prop/interface/variant metadata.
   - Read all JSON/YAML files in `figma-variants/` for Figma variant mappings.

2. **Map Figma Variants to Component Props**
   - For each component, match Figma variant properties to corresponding prop names/types.
   - Use `potentialFigmaMapping` hints from YAML to guide mapping.
   - Log warnings for unmapped or ambiguous variants.

3. **Generate `.figma.tsx` Files**
   - For each component, create a new file:
     ```
     chakra-ui/packages/react/src/components/<component>/<component>.figma.tsx
     ```
   - The file should:
     - Import the original component and its prop types.
     - Export a wrapper/component with Figma variant props mapped to React props.
     - Include prop types and default values.
     - Add comments for Figma mapping and variant documentation.
     - Use robust error handling and clear logging for each step.

4. **Handle Edge Cases**
   - If a component is a re-export or has no props, generate a minimal wrapper.
   - If Figma variants do not match component props, log a warning and add TODO comments in the output file.

5. **CLI Interface**
   - Add a script: `scripts/generateFigmaConnect.js`
   - Support options:
     - `--dry-run` (preview output)
     - `--overwrite` (replace existing files)
     - `--filter <component>` (single component)
     - `--verbose` (detailed logging)

## 🛠️ Technical Implementation

### Required Functions

1. **`scanComponentPropsDirectory()`**
   - Read all YAML files in `components-props/`
   - Parse prop definitions, recipe variants, and Figma mapping hints

2. **`scanFigmaVariantsDirectory()`**
   - Read all JSON/YAML files in `figma-variants/`
   - Parse Figma variant definitions

3. **`mapFigmaVariantsToProps(componentProps, figmaVariants)`**
   - Match Figma variant keys to component prop names/types
   - Use `potentialFigmaMapping` for guidance
   - Return mapping object and log any ambiguities

4. **`generateFigmaTsxFile(componentName, mapping, options)`**
   - Build `.figma.tsx` file content
   - Import original component and prop types
   - Export wrapper with mapped props
   - Add comments for mapping and documentation
   - Write file to correct directory, respecting `--dry-run` and `--overwrite`

5. **`writeFigmaTsxFile(filePath, content, options)`**
   - Write or preview file output
   - Handle file naming and directory creation
   - Log actions and errors

6. **`runCLI()`**
   - Parse CLI arguments
   - Filter components if requested
   - Run generation for all or filtered components
   - Log summary and errors

## 📝 Output Example

**Button.figma.tsx**
```tsx
// Auto-generated by Figma Code Connect Script
import { Button } from './button'
import type { ButtonProps } from './button'

/**
 * Figma variant mapping:
 * - size: "2xs" | "xs" | "sm" | "md" | "lg" | "xl" | "2xl"
 * - variant: "solid" | "subtle" | "surface" | "outline" | "ghost" | "plain"
 * - loading: boolean
 */

export type ButtonFigmaProps = Omit<ButtonProps, 'size' | 'variant'> & {
  size?: '2xs' | 'xs' | 'sm' | 'md' | 'lg' | 'xl' | '2xl'
  variant?: 'solid' | 'subtle' | 'surface' | 'outline' | 'ghost' | 'plain'
  loading?: boolean
}

export const ButtonFigma = (props: ButtonFigmaProps) => <Button {...props} />
```
